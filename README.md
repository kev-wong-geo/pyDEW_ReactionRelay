# pyDEW_TDR
Time-decompression relay for pyDEW. Work in progress.
Includes three files:
* 0_TDR.ipynb : jupyter notebook with commented code for the relay function and setup
* pyDEW_functions : supplementary functions for pyDEW
* relay_functions : structural functions for the relay function
* EQ3_pickups_GS.xlsx : original data collected by Guillaume Siron, used as a basefile for the slab fluid compositions
